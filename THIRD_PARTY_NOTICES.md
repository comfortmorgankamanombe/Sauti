# Third-party components

Sauti bundles the following open-source components, unmodified unless noted. Each one stays under its own license.

| Component | Location | License |
|---|---|---|
| TensorFlow.js (core, converter, CPU backend) | `lib/tf-*.min.js` | Apache-2.0 |
| Universal Sentence Encoder QnA model | `models/use-qna/` | Apache-2.0 |
| Tokenizer logic adapted from `@tensorflow-models/universal-sentence-encoder` | `ask.js` (modified) | Apache-2.0 |
| Tesseract.js and tesseract.js-core | `lib/tesseract/` | Apache-2.0 |
| Tesseract English trained data | `models/tesseract-eng/` | Apache-2.0 |
| PDF.js (Mozilla) | `lib/pdfjs/` | Apache-2.0 |
| Vosk browser runtime | `lib/vosk/` | Apache-2.0 |
| Vosk small English model | `models/vosk-small-en/` | Apache-2.0 |
